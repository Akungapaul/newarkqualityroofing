## NJ Specific — How Does NJ Code Treat Coating Versus Replacement?
Coating not counted as a roof covering layer (preserves overlay allowance); replacement tear-off resets layer count; 25% permit threshold + full-removal triggers (N.J.A.C. 5:23-6.4 / 5:23-2.7(c)); dry-substrate requirement in Zone 4A–5 (31.5 in snow, 35–45 freeze-thaw).
