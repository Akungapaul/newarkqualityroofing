## introParagraphs
1. Defines both by function + differentiator (R38): EPDM = EPDM single-ply, adhesive/tape seams; TPO = thermoplastic-polyolefin single-ply, hot-air-welded seams + reflective white surface.
2. Failure modes per side, NRCA-attributed: EPDM → seam separation (dominant) + puncture / shrinkage / ponding-stretch; TPO → welded-seam breakdown (dominant) + chemical attack + thermal-shock cracking from plasticizer migration.

## verdict
- **winner:** EPDM wins on charted lifespan + cold-weather seam simplicity; TPO wins on reflective cool-roof performance.
- **reasoning:** EPDM over TPO when prioritizing charted longevity + field-repairable seams — 15–25 vs 7–20 yr (InterNACHI), adhesive/tape seams patch without a welder.
- **alternateScenario:** TPO over EPDM when summer cooling load leads — ~0.70–0.85 SR (ASTM C1549, CRRC) + reflective roof stays >50°F cooler (DOE).
